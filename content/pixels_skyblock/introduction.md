Pixels Skyblock is a remake of the classic Skyblock map, updated for newer versions of Minecraft. You start on a tiny island floating in the void and have to survive with what little you have. Over 50 custom advancements guide you from your first tree all the way to the Ender Dragon.

## Features

- The classic Skyblock layout, ported from the original map
- An endless void that works on newer versions
- Biomes and structure boundaries still exist, so you can find a Nether Fortress or the End Portal frame and beat the game
- 51 custom [advancements](advancements) in their own Skyblock tab, split into copper, iron and gold tiers
- Available as a normal and a **Hardcore** version

## Normal and Hardcore

Both versions are the same world. The only difference is that the Hardcore version has Hardcore mode turned on. This cannot be changed later.
