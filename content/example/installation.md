# Installation

Pick your loader. The tabs further down follow your choice.

::: tabs
@tab Fabric
1. Install :loader[Fabric] for your Minecraft version.
2. Download [Fabric API](https://modrinth.com/mod/fabric-api).
3. Put both jars into your `mods` folder.
@tab Quilt
1. Install :loader[Quilt] for your Minecraft version.
2. Download Quilted Fabric API.
3. Put both jars into your `mods` folder.
:::

## Where is the mods folder?

::: tabs
@tab Fabric
`%appdata%\.minecraft\mods`
@tab Quilt
`%appdata%\.minecraft\mods` (same folder as Fabric)
:::

::: warning
Never mix mods for different Minecraft versions in one folder.
:::

::: details The game crashes on start
Check that every mod matches your Minecraft version and loader, then remove mods one by one until the crash stops.
:::
