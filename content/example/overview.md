This is the first page of a project. Its title comes from `project.json`, unless the file starts with its own `# Heading`.

::: info How pages work
Every page is a Markdown file in `content/<project>/`. The order in the sidebar comes from `pages` in `project.json`.
:::

## Features

- Pages written in plain Markdown
- [gold]Colors[/] from the website's color map
- Collapsible sections, callouts and tabs
- Loader chips like :loader[Fabric, Quilt]
