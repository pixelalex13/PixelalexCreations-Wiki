## Requirements

| Requirement | Notes |
|---|---|
| :loader[Fabric] or :loader[Quilt] Loader | For your Minecraft version |
| [Fabric API](https://modrinth.com/mod/fabric-api) | Required |

::: info Client-side only
The mod only has to be installed on your game. It works on any server, including vanilla servers.
:::

## Steps

::: tabs
@tab Fabric
1. Install :loader[Fabric] Loader for your Minecraft version.
2. Download Fabric API and put it into your `mods` folder.
3. Download Pixels F3 from [Pixelalex Creations](https://www.pixelalexcreations.net/mods/#pixels_f3) and put it into your `mods` folder.
4. Start the game.
@tab Quilt
1. Install :loader[Quilt] Loader for your Minecraft version.
2. Download Fabric API and put it into your `mods` folder.
3. Download Pixels F3 from [Pixelalex Creations](https://www.pixelalexcreations.net/mods/#pixels_f3) and put it into your `mods` folder.
4. Start the game.
:::
