## v1.3.1
::: changelog
## Changes

- Removed the Ender Dragon and Wither Spawn Eggs from the Creative Inventory, as this didn't fit in with the mod. This feature is being moved to the Zephyr Mod, also by pixelalex13
- Removed the Giant Spawn Egg and the Illusioner Spawn Egg, as they didn't fit in with the mod. Both are being moved to the Zephyr Mod, also by pixelalex13
[gray]*Due to these changes, all versions below 1.3.1 from Embellishments will not work with Zephyr 1.2 and onwards.*[/]
- Removed the Mannequin Spawn Egg, as it didn't fit in with the mod and wasn't fully developed

## Bug Fixes

- Fixed the Encased Redstone being in the wrong position in the Redstone Blocks creative tab (only in Minecraft 26.2)
:::

## v1.3
::: changelog
## Additions

- An Encased Redstone block that is like an redstone wire but as a full block
- A crafting recipe for the Encased Redstone block consisting of copper and redstone dust

## Changes

- Mannequin spawn egg texture changed to Alex instead of Steve
:::

## v1.2
::: changelog
## Additions

- An Invisible Name Tag crafted using an invisibility potion and a name tag, that when worn on the head disables the players name tag and makes him disappear from the locator bar
- An Name Tag Visibility attribute with the standard value of 1.0 and when changed to 0.0 disables the target players name tag

**Note:**
- The Invisible Name Tag crafting recipe is hard coded, because it uses the invisibility potion and therefore wont show up in the recipe book
:::

## v1.1
::: changelog
## Additions

- Banners can now be worn on the head
- Glass, stained glass and tinted glass can now be worn on the head
- Bones, cod, end rods, feathers, fence gates, leads, lightning rods and spyglasses can now be worn on the head (Because of the special way the render on the head)
:::

## v1.0
::: changelog
## Additions

- TNT can now be defused by interacting with it using shears
- Defused TNT can now be rearmed by interacting with it using gun powder
- New spawn eggs for the Illusioner, Giant and Mannequin are available in the creative menu
- The Ender Dragon and Wither spawn eggs are now available in the creative menu
- A Eye Sensor block that gives out a redstone signal relative from how close to the center of the block you look
- A crafting recipe for the Eye Sensor block consisting of end stone, echo shards, redstone dust and an eye of ender
:::
