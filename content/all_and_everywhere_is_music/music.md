## How it works

Normally, Minecraft picks music based on where you are: the main menu, the biome, the dimension, Creative mode or being underwater all have their own tracks. This pack puts all tracks into one shared playlist and uses it everywhere:

| Situation | Plays |
|---|---|
| Main menu | All tracks |
| Overworld (all biomes with own music) | All tracks |
| Creative mode | All tracks |
| Underwater | All tracks |
| Nether (all biomes) | All tracks |
| The End | All tracks |
| Ender Dragon fight | All tracks |
| Credits | All tracks |

::: info Deep Dark
The Deep Dark is not covered yet and still plays its normal music. This will be fixed in a future update.
:::

The pack does not add new audio files. It uses the music that is already in the game.
