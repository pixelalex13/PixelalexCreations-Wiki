# :icon[images/shifting_book.png]{size=36} Shifting Book

The Shifting Book trades experience levels for a random enchanted book. It always has the enchantment glint, stacks up to 16 and can be placed in Chiseled Bookshelves.

## Using the Shifting Book

Hold the Shifting Book and press the use key (right-click by default).

- It costs **5 levels**.
- The Shifting Book is used up and you get one random enchanted book. If your inventory is full, the book drops at your feet.
- After using it, there is a **3 second cooldown**. You can change it in the [configuration](configuration).
- In Creative mode, it costs no levels and is not used up.

::: warning Not enough levels
If you have fewer than 5 levels, a message appears above your hotbar and nothing happens. The cooldown still starts.
:::

Any enchanted books work, no matter which enchantments they have. A good way to get rid of books you do not need.

## Possible results

First, the level of the book is chosen. Then one enchantment of that level is picked, each with the same chance.

| Level | Chance |
| :---: | :---: |
| I | 40% |
| II | 30% |
| III | 15% |
| IV | 10% |
| V | 4% |
| Treasure | 1% |
