## Requirements

| Requirement | Notes |
|---|---|
| :loader[Fabric] or :loader[Quilt] Loader | For your Minecraft version |
| [Fabric API](https://modrinth.com/mod/fabric-api) | Required |

::: info Client and server
The mod has to be installed on the server and on every client. In singleplayer, simply install it like any other mod.
:::

::: tip New world recommended
Spirit Crystal Ore and Graveyards only generate in new chunks. In an existing world, you have to explore areas you have not visited yet.
:::

## Steps

::: tabs
@tab Fabric
1. Install :loader[Fabric] Loader for your Minecraft version.
2. Download Fabric API and put it into your `mods` folder.
3. Download Spirit Scape from [Pixelalex Creations](https://www.pixelalexcreations.net/mods/#spirit_scape) and put it into your `mods` folder.
4. Start the game or server.
@tab Quilt
1. Install :loader[Quilt] Loader for your Minecraft version.
2. Download Fabric API and put it into your `mods` folder.
3. Download Spirit Scape from [Pixelalex Creations](https://www.pixelalexcreations.net/mods/#spirit_scape) and put it into your `mods` folder.
4. Start the game or server.
:::

On a dedicated server, put both files into the server's `mods` folder.

## Languages

The mod is available in **English** and **German**.
