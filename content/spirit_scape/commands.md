## /spawnevent

Spawns a world event.

```
/spawnevent dimensional_rift
```

| Event | Description |
|---|---|
| `dimensional_rift` | Opens a [Dimensional Rift](dimensional_rift) near a random player |

Requires operator permission level **2** or higher.

If the rift cannot open, for example because the ground at the chosen spot is below Y 62, an error message is shown. Just try again.

::: warning
The rift currently opens near a random player, not necessarily near the player who ran the command. See [Known Issues](known_issues).
:::
