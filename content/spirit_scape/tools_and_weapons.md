The Spirit Crystal set includes a **Sword, Spear, Shovel, Pickaxe, Axe and Hoe**.

Spirit Crystal tools are a sidegrade to Netherite, similar to how Copper relates to Stone: they mine **faster**, but deal the same damage, have the same durability and the same attack speed.

## Stats

| Stat | Spirit Crystal | Netherite |
|---|:---:|:---:|
| Durability | 2031 | 2031 |
| Mining speed | [green]9.5[/] | 9 |
| Attack damage | Same as Netherite | |
| Attack speed | Same as Netherite | |
| Enchantability | 15 | 15 |

Spirit Crystal tools can mine everything a Netherite tool can mine.
