Spirit Scape adds a few tags. They are mainly useful for data pack and mod developers.

## Block tags

| Tag | Description |
|---|---|
| `minecraft:needs_netherite_tool` | Blocks that need a Netherite tool or better. Vanilla Minecraft only has tags up to `needs_diamond_tool`, so this one is added by Spirit Scape. Currently empty. |
| `spirit_scape:needs_spirit_crystal_tool` | Blocks that need a Spirit Crystal tool. Currently includes `#minecraft:needs_netherite_tool`. |
| `spirit_scape:incorrect_for_spirit_crystal_tool` | Blocks Spirit Crystal tools cannot mine. Currently empty. |

## Item tags

| Tag | Description |
|---|---|
| `spirit_scape:spirit_crystal_tool_materials` | Items that repair Spirit Crystal tools. Contains the Spirit Crystal. |
| `spirit_scape:repairs_spirit_crystal_armor` | Items that repair Spirit Crystal armor. Contains the Spirit Crystal. |
